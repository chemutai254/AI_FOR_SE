# MNIST Digit Classification

## Description
This project focuses on building and training Deep Learning models to recognize handwritten digits (0-9) using the famous MNIST dataset. It explores implementations using both PyTorch and TensorFlow frameworks.

## Key Objectives
- Load and preprocess the MNIST dataset.
- Design and train Convolutional Neural Networks (CNNs).
- Evaluate model accuracy on test data.

## Dataset
- **Name**: MNIST (Modified National Institute of Standards and Technology) database.
- **Content**: 60,000 training images and 10,000 testing images of handwritten digits.

## Tech Stack
- **Languages**: Python.
- **Frameworks**: PyTorch, TensorFlow/Keras.
- **Tools**: Jupyter Notebook.

## Project Structure
- `mnist_pytorch.ipynb`: Implementation using PyTorch.
- `mnist_tensor.ipynb`: Implementation using TensorFlow.
- `mnist.py`: Python script for the model.
- `mnist_cnn_model.pth`: Saved PyTorch model.
- `Theoretical Understanding.pdf`: Background theory on the approach.

## How to Run
1.  **PyTorch Version**: Open `mnist_pytorch.ipynb` and run the cells to train the PyTorch model.
2.  **TensorFlow Version**: Open `mnist_tensor.ipynb` and run the cells to train the TensorFlow model.
3.  **Script**: Run `python mnist.py` to execute the standalone script.
