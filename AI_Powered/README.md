# AI-Powered Software Development

## Description
This project explores how AI tools can enhance the software development process. It covers two main areas: AI-assisted code completion and AI-driven automated testing.

## Key Features
- **AI Code Completion**: Using tools like GitHub Copilot or Tabnine to generate efficient Python code (e.g., sorting dictionaries).
- **Automated Testing**: Leveraging AI-enhanced frameworks (like Selenium or Testim.io) to automate web application testing (e.g., login pages).

## Tech Stack
- **Languages**: Python.
- **Tools**: GitHub Copilot/Tabnine, Selenium IDE/Testim.io.
- **Files**: `login_automation.py`, `product.ipynb`.

## Project Structure
- `product.ipynb` / `product_co.ipynb`: Demonstrations of AI code completion tasks.
- `login_automation.py` / `login_automation.ipynb`: Scripts for automated login testing.
- `login_failure.html` / `login_failure.png`: Artifacts from automated testing runs.
- `Breast_Cancer_Diagnosis.pdf`: Related documentation.

## How to Run
1.  **Code Completion**: Open `product.ipynb` in Jupyter Notebook to see the sorting logic comparison.
2.  **Automated Testing**: Run `python login_automation.py` (ensure Selenium drivers are installed) to execute the login test.
